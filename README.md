# TRACKSTAR EARTH sample warehouse

Public staging repository for the TRACKSTAR DAW EARTH sample warehouse.

This first release contains the **reduced 17-instrument catalog**. Audio assets are not marked ready until the source WAVs have been downloaded from the audited CC0 sources, normalized, uploaded as release assets, and verified with HTTP 200/range checks. Until then, the TRACKSTAR DAW intentionally uses its procedural fallback builders.

Removed from the original catalog because no sufficiently convincing, redistributable CC0 source was verified: electric piano, clavinet, drawbar organ, organ, sub bass, choir ahh, and choir ooh.

The `earth-v1-staging` release is a public manifest/release scaffold, not a claim that the audio warehouse is complete.
